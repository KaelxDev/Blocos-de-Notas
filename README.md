# Editor de Texto — V1.0

Um bloco de notas simples criado em **Python** utilizando a biblioteca **Tkinter**.

## ✨ Funcionalidades — V1.0

### 📁 Menu Arquivo

* **Novo** — Cria um novo documento.
* **Abrir** — Abre arquivos de texto existentes.
* **Salvar** — Salva o documento atual.
* **Salvar Como** — Permite escolher o nome e o local do arquivo.
* **Sair** — Fecha o aplicativo.

### ✏️ Menu Editar

* **Recortar**
* **Copiar**
* **Colar**
* **Selecionar Tudo**

As funções de edição são integradas à **área de transferência do sistema**.

### ⌨️ Atalhos de Teclado

| Atalho     | Função          |
| ---------- | --------------- |
| `Ctrl + N` | Novo documento  |
| `Ctrl + O` | Abrir arquivo   |
| `Ctrl + S` | Salvar arquivo  |
| `Ctrl + A` | Selecionar tudo |

### 📜 Barra de Rolagem

Possui **barra de rolagem** para facilitar a leitura e edição de textos longos.

### 🔤 Codificação UTF-8

O editor utiliza **UTF-8** para abrir e salvar arquivos, garantindo o suporte correto a caracteres especiais e acentuados, como:

`ç`, `ã`, `á`, `é`, `ê`, `õ`, `ú`, entre outros.

## 🛠️ Tecnologias

* **Python**
* **Tkinter**
* **UTF-8**

## 📌 Versão

**V1.0**
